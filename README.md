# 譚良蔚 Sally Tam 教育專業作品集

Sally Tam 的個人教育作品集，聚焦資訊及通訊科技教育、設計與科技、STEAM 跨學科學習及校本數字教育實踐。

## 內容定位

- Sally Tam 是網站唯一主要人物及結構化資料中的 Person 實體
- 作品以 Sally 的教學設計、項目帶領、系統開發及校內推行為主
- 學生只以獲帶領團隊方式呈現，不使用個人姓名作 SEO 關鍵字
- 協作者只在有其出現的活動合照 caption 中按實際身份說明
- 技術描述以教育界可理解的字眼呈現，並連結 DSE 資訊及通訊科技概念

## 代表案例

- `/project/nfc-smartmart`：NFC 梅記智能超市、完整獎項與交流紀錄、15 張活動相片
- `/project/school-room-booking-system`：校園房間預約、數據管理、分層使用權限及資訊保安
- `/project/teacher-duty-scheduler`：教師當值編排、邏輯規則、數據處理及安全存取

## 本機開發

```bash
yarn install
yarn dev
```
