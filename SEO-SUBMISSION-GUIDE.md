# Search Engine Submission Guide

The technical site is ready for submission at `https://www.sally-tam.com`.

## Google Search Console

1. Add the **Domain property** `sally-tam.com` in Google Search Console.
2. Copy Google's TXT verification record into Cloudflare DNS and complete verification.
3. Submit `https://www.sally-tam.com/sitemap.xml` under Sitemaps.
4. Inspect the homepage and four project URLs, then request indexing.
5. Check Page indexing, HTTPS, Core Web Vitals, and Enhancements weekly until the first crawl settles.

## Bing Webmaster Tools

1. Import the verified Google Search Console property or add `sally-tam.com` directly.
2. Submit `https://www.sally-tam.com/sitemap.xml`.
3. Review Site Scan and URL Inspection after Bing recrawls the site.

## What to measure

- Indexed pages: target all 8 sitemap URLs.
- Branded impressions: `譚良蔚`, `Sally Tam`, and `譚良蔚 教師`.
- Relevant long-tail impressions: Hong Kong STEAM teaching cases, design and technology teaching, Micro:bit, Onshape, programming, and open-data education.
- Engagement: Vercel Analytics page views and referrers, with Speed Insights for real-user performance.

Do not use Google's Indexing API for these portfolio pages; it is intended for specific eligible content types rather than ordinary webpages.
